# Anti-Vibecoding Rules & Design System Mandate

## Mandatory Principles
1. **Never generate generic placeholder slop**: No "Lorem Ipsum", "Card 1", "User 123", or unbranded purple glow orbs.
2. **Brand Precision**: Sime Darby Property brand styling (Crimson `#9E1B32` / `#8B1D24`, Champagne Gold `#C5A880`, Slate `#1F2421`, high contrast white surfaces).
3. **Domain Grounding**: Genuine Malaysian township context — City of Elmina, KL East Mall, Bandar Bukit Raja, Ara Damansara, Oasis Square; authentic OKU parking permits, JKM standards, Polis Bantuan (Township Auxiliary Police) dispatch.
4. **Android Native Experience**: Material 3 ergonomics, standard Android bottom navigation bar, edge-to-edge layout, tactile feedback, drawer/sheet navigation, large accessible touch targets (min 48x48dp).
5. **Interactive State Completeness**: Real working state for all 3 features:
   - AccessMap with live toggles (wheelchair ramps, tactile paving, elevators, OKU restrooms), real step-free route pathing between points, turn-by-turn directions, elevation/slope indicators.
   - Community Buddy System with verified resident precinct matching, real-time request creation, volunteer accepting flow, live messaging/coordination, and task completion.
   - Smart OKU Parking Protection with live bay telemetry across townships, quick photo report dispatch to Polis Bantuan, live alert notifications, and ticket status tracking.
6. **Role Switcher**: Persistent user role switcher (Public Visitor, PRIME Member, Verified Resident, Auxiliary Security Officer) to easily audit and test all user role requirements.
