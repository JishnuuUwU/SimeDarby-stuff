# Anti-Vibecoding Design & Engineering Standard

## 1. What is "Vibecoding Slop" & Why We Ban It
"Vibecoding" refers to unanchored AI code generation characterized by:
- **Generic Visual Fingerprints**: Indiscriminate violet/purple glow orbs, generic floating cards with blurry backdrop-filters, uncurated Inter font everywhere, random border radii.
- **Surface-Level Feature Fakes**: Three centered cards with generic stock icons, non-functional inputs, dummy buttons that do nothing or trigger empty alert dialogs.
- **Zero Domain Grounding**: Placeholder names like "User 123", "Mall A", "Task 1", missing localized Malaysian context, fake generic currencies or unauthentic terminology.
- **Incomplete State Handling**: No loading skeletons, no real-time transition animations, broken responsive layouts on mobile viewports, ignored edge cases.

## 2. The Anti-Vibecoding Craft Mandate
Every interface generated must uphold the highest standards of professional product design:

### A. Intentional Brand & Visual Tokens
- **Brand Identity**: Reflect Sime Darby Property's corporate identity — deep crimson/burgundy heritage primary (`#8B1D24` / `#9E1B32`), warm gold/champagne accents (`#C5A880`), deep slate/carbon surfaces (`#111418`, `#1A1E24`), clean warm whites (`#FBFBFB`).
- **Typography**: Editorial typography hierarchy using Plus Jakarta Sans / Outfit for confident headlines and crisp numeric data; legible system sans for high-readability body copy.
- **Tactile Depth**: Subtle border strokes (`1px solid rgba(255,255,255,0.08)` or `rgba(0,0,0,0.06)`), authentic shadows tuned to light/dark themes, zero blurry garish neon drop shadows.

### B. Realistic Domain Grounding (Sime Darby Property Context)
- **Townships & Assets**: Real Sime Darby Property developments — City of Elmina (Elmina Lakeside Mall, Central Park, Rainbow Bridge, Elmina Valley), KL East (KL East Mall, The Ridge, KLGCC Resort), Bandar Bukit Raja (Athira, Gateway), Ara Damansara (Oasis Square).
- **Resident Verification**: Realistic precinct identification, MyKad verification badges, household residency proofs, Polis Bantuan (Township Auxiliary Police) dispatch integration.
- **Malaysian OKU Standards**: Authentic Malaysian OKU (Orang Kurang Upaya) parking permit verification, JKM (Jabatan Kebajikan Masyarakat) card registry standards, tactile paving routes (guiding yellow lines vs dot warning tiles), universal accessible toilet (Tandas OKU) specifications.

### C. Complete Interactive State Machines
- Every interactive element (filter chips, map markers, report buttons, volunteer match cards) must feature:
  - Default / Rest state
  - Hover / Pressed haptic response
  - Active / Filtered state
  - Loading skeleton & spinner state
  - Complete confirmation & feedback loops (toasts, modal alerts, ticket tracking)

### D. Multi-Role Architecture
- Provide switchable user personas directly in the UI so evaluators can test every angle:
  1. **Public Visitor**: Browsing township commercial zones, parking, and accessible paths.
  2. **PRIME Member**: Accessing member privileges, tier rewards, and priority booking.
  3. **Verified Resident**: Accessing Community Buddy requests, neighbor matching, and security escalation.
  4. **Township Auxiliary Security (Polis Bantuan)**: Receiving live OKU parking misuse alerts, patrol dispatch, and bay enforcement feeds.
