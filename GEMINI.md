# Sime Darby Property Mobile Application (Accessibility & Township Extension)

## Core Guidelines
- Follow `.agents/skills/anti-vibecoding/SKILL.md` and `.agents/skills/accessible-design-systems/SKILL.md`.
- Adhere to Sime Darby Property design identity and Malaysian OKU accessibility guidelines (MS 1184:2014 Universal Accessibility Code of Practice).
- Ensure all 3 key features (AccessMap, Community Buddy System, Smart OKU Parking Protection) are fully interactive, intuitive, and accessible.
- Support Android app packaging via Capacitor and responsive mobile device emulation.
